# MealMate

Практическая работа по дисциплине **«Управление информационными системами»**.

Telegram-бот для персонализированного подбора блюд с учётом вкусовых предпочтений, диетических ограничений и настроения пользователя.

## Описание системы

**MealMate** — информационная система в виде чат-бота, которая:

- хранит профили пользователей и каталог блюд в JSON-файлах;
- позволяет настраивать предпочтения (вкус, диета, настроение);
- рекомендует блюда по заданным критериям;
- сохраняет избранное и предоставляет ссылки на рецепт и заказ.

### Архитектура

```
MealMate/
├── bot.py              # Точка входа, инициализация Pyrogram-клиента
├── keyboards.py        # Клавиатуры команд и inline-кнопок
├── handlers/           # Обработчики команд Telegram
│   ├── start.py
│   ├── help.py
│   ├── taste_settings.py
│   ├── choice.py
│   └── favorites.py
└── data/
    ├── database.py     # Работа с users.json и dishes.json
    ├── users.json      # Данные пользователей
    └── dishes.json     # Каталог блюд
```

### Команды бота

| Команда | Назначение |
|---------|------------|
| `/start` | Приветствие и краткое описание |
| `/help` | Справка по командам |
| `/taste_settings` | Настройка вкусов, диеты и настроения |
| `/choice` | Рекомендация блюда по предпочтениям |
| `/favorites` | Список избранных блюд |

## Технологии

- **Python 3.10+**
- **Pyrogram** — взаимодействие с Telegram Bot API
- **python-dotenv** — загрузка переменных окружения
- **JSON** — хранение данных (пользователи, каталог блюд)

## Установка и запуск

### 1. Клонирование и окружение

```bash
git clone <url-репозитория>
cd MealMate
python -m venv venv
```

**Windows (PowerShell):**

```powershell
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 2. Зависимости

```bash
pip install pyrogram tgcrypto python-dotenv
```

### 3. Настройка переменных окружения

Скопируйте пример файла и заполните своими значениями:

```bash
copy .env.example .env
```

В `.env` укажите:

- `API_ID` и `API_HASH` — с [my.telegram.org](https://my.telegram.org/apps);
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).

> Файл `.env` не попадает в репозиторий (см. `.gitignore`).

### 4. Запуск бота

```bash
python bot.py
```

После успешного запуска в консоли появится сообщение: `Бот MealMate запущен!`

## Данные

- `data/users.json` — предпочтения и избранное пользователей;
- `data/dishes.json` — каталог блюд (название, описание, теги, ссылки, ограничения).

При первом запуске, если `dishes.json` отсутствует, создаётся набор примерных блюд.
